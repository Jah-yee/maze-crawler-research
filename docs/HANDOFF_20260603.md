## 5. 关键 meta 发现 (这些是用血换的)

1. **gate 阈值**: 80g 自对弈噪声 \|z\| ≤ 1.15, 之前 z≥1.5 gate 在假阳率边缘。**新 gate: 160g + z≥1.7, 或 200g + z≥1.5**。
2. **off-by-one 配对 bug**: 早期所有用 `env.steps[t].action` 当 "obs(t) 触发的动作" 的工作都错了——那是产生 obs(t) 的动作。W-Tree 全部规则因此作废。W-DataDriven 修正了。
3. **离线 precision ≠ ELO**: W-Tree 决策树 precision 0.97 的 R1 实测 z=+0.28 (触发率=0)。**离线指标只能当 hypothesis 生成器, 不是 ground truth**。
4. **v37 是局部最优**: 在它当前的"启发式 + BFS + 经济门控"搜索空间里, 任何窄改动几乎都会让它退化。**真突破必须换搜索方式 (2-ply BFS+cost), 不是叠 patch**。
5. **W7 工程原则全部得到血证**:
   - "Never break the active slot" — v26/v40/v42 都验证过
   - "Reject if z<1.7" — 之前 z=1.5 让 v40 假阳上线导致掉 90 ELO
   - "patch over refactor until 5 patches" — 我们到第 25 次了, 该用 v50 容器
6. **W-Tree off-by-one bug** 也说明 **W6/W9 推荐的高 ROI patches** 大多源于同样的"观察 ≠ 触发"混淆。值得重新审视所有"+20-100 ELO"的研究 claim。
